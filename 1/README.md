## Dia 1 de c++ | Gerenciador de Inventário Simples

Escreva um programa em C++ que faça o seguinte:

- Defina uma `(struct)` chamada "Item" que tenha duas propriedades: string nome e int quantidade.
  
- No main, crie um `(std::vector)` do tipo Item para guardar o inventário do seu personagem.
  
- Adicione pelo menos dois itens diferentes usando o `(.push_back())` (por exemplo: "Poção de Vida" com quantidade 5, e "Espada de Ferro" com quantidade 1).
  
- Use um laço for para percorrer o vetor e imprimir na tela o nome e a quantidade de cada item cadastrado.
